# Lab 11 — The Four Locations of Git

| Command | Moves what | From | To |
|---|---|---|---|
| git add | Current file content | Working Tree | Staging Area |
| git commit | Snapshot of staged files | Staging Area | Local Repository |
| git push | Commits the remote lacks | Local Repository | Remote |
| git restore --staged | Last committed file version | Local Repository | Staging Area |
| git restore | Staged file version | Staging Area | Working Tree |
